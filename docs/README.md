# Docs

Dotfiles for macOS. The root `README.md` is the setup guide. These pages are the longer notes. Recipes in `just/dotfiles.just` stay on preview until Axel asks to apply a change. Do not run `chezmoi apply` from a recipe.

The license is PolyForm Noncommercial 1.0.0 (`LICENSE`). Versions published before the 2026-11-12 license change remain available under Apache-2.0. What changed, and why, is in `CHANGELOG.md`.

`docs/archive/` holds notes that are no longer the living record. The dated update log is there. Do not add new session notes to it.
