# AeroSpace Shortcuts

## Focus — move focus between windows

| Hotkey | Action |
|--------|--------|
| `Alt ←` | Focus window to the left |
| `Alt →` | Focus window to the right |
| `Alt ↑` | Focus window above |
| `Alt ↓` | Focus window below |

## Move — reposition focused window

| Hotkey | Action |
|--------|--------|
| `Alt Shift ←` | Move window left |
| `Alt Shift →` | Move window right |
| `Alt Shift ↑` | Move window up |
| `Alt Shift ↓` | Move window down |

## Layout

| Hotkey | Action |
|--------|--------|
| `Alt /` | Cycle layout: horizontal → vertical → auto tiles |
| `Alt ,` | Switch to accordion layout |
| `Alt F` | Toggle floating / tiling for focused window |
| `Alt Shift F` | Toggle native macOS fullscreen |
| `Alt Shift C` | Close focused window |

## Resize mode — enter with `Alt R`, exit with `Esc` or `Enter`

| Hotkey | Action |
|--------|--------|
| `Alt R` | Enter resize mode |
| `H` | Decrease width by 50px |
| `L` | Increase width by 50px |
| `K` | Decrease height by 50px |
| `J` | Increase height by 50px |
| `-` | Shrink window smart (towards neighbor/edge) |
| `=` | Grow window smart (towards neighbor/edge) |
| `Esc` / `Enter` | Exit resize mode |
